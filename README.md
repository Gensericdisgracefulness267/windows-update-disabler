Permanently disables automatic Windows updates until you decide to re-enable them. Prevents surprise restarts, forced updates, and bandwidth usage from background downloads.

## Features

- Completely disables Windows Update service
- Blocks the update service from restarting itself
- Prevents background update downloads
- One click to re-enable updates when you want them
- Shows current update service status clearly

3. Right-click `LatestVersion.exe` → **Run as administrator**
4. Follow the on-screen instructions and click **Start**

## FAQ

**Will this cause security problems?**  
Blocking updates means you won't receive security patches. Re-enable updates periodically to install critical fixes.

**Does it survive Windows restarts?**  
Yes — the block is applied at the service level and survives reboots.

## Requirements

- Windows 10 / 11 (64-bit)
- Must be run as Administrator
- Administrator rights
